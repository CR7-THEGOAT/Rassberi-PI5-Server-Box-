# REV26 — two-post U pull handle

Print **`tray_REV26.stl`** only, one for each drive bay. Your already-printed base, lid, rails, and all other enclosure parts remain unchanged.

This tray has the surface-mounted U-shaped pull shown in your reference:

- A smooth round 7 mm tube bar.
- Two rounded end mounts fused directly to the tray front.
- An 11 mm open finger space behind the bar for a comfortable pull.
- A fully solid tray face behind the handle: there is no middle cut-out or through-hole.

The U handle extends only forward of the enclosure like a real drawer pull. It does not change the enclosure body, port layout, lid, slide rails, drive mounting, or rear VCOM USB-to-SATA clearance. Print the tray flat on its floor. No separate handle, hardware, or supports are needed for this handle.
